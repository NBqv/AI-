# 🎨 Voice Draw — 语音画画

**用声音画画的儿童绘画工具，2-4 岁幼儿也能轻松上手。**

![界面截图](https://via.placeholder.com/800x100/667eea/ffffff?text=Voice+Draw)

说一句"画个猫再画个花再画个房子"，就能在画布上画出来。支持普通话语音识别，内置 159 个简笔画模板，也可通过 Ollama 或本地 AI 实时生成。

---

## 快速开始

```bash
# 1. 打开前端（需要 HTTP 服务）
python -m http.server 8081

# 2. 浏览器打开
# http://localhost:8081/

# 3. （可选）启动 AI 后端
cd backend
uvicorn server:app --host 0.0.0.0 --port 8080

# 4. 点击"🎤 开始说话"，说出你想画的
```

**不需要 AI 后端也能用**——语音识别和本地命令解析完全在浏览器内完成，159 个模板离线可用。

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | 纯 HTML + CSS + JavaScript（无框架） |
| 后端 | Python FastAPI |
| AI 推理 | Ollama (qwen2.5:7b) / 本地 transformers (Qwen2.5-1.5B) |
| 语音识别 | Web Speech API（浏览器内置） |
| 画布 | HTML Canvas 2D |

## 指令大全

### 🎨 画图指令

| 示例 | 说明 |
|------|------|
| `画个猫` | 模板匹配，零延迟 |
| `画个红色的圆` | 指定颜色 |
| `画个房子再画个树` | 连续画，自动错位不重叠 |
| `在兔子左边画个乌龟` | 相对定位 |
| `擦掉兔子` | 擦除 |
| `把企鹅移到右边` | 移动 |

## 项目结构

```
voice_draw/
├── index.html           # 主页面
├── script.js            # 全部前端逻辑
├── style.css            # 儿童友好 UI
├── test_review.html     # 模板评审页面
├── design.md            # 设计文档
├── README.md            # 本文件
└── backend/
    ├── server.py        # FastAPI 后端
    ├── aliases.json     # 159 个简笔画模板 + 别名词典
    ├── generate_templates.py   # 调用 API 批量生成模板
    ├── handwrite_templates.py  # 手写 33 个模板
    ├── validate_templates.py   # 模板验证脚本
    ├── patch_*.py       # 功能补丁脚本
    └── requirements.txt
```
